# RESPONSIVE DESIGN

Do not simply shrink the desktop version.

Desktop:
- cinematic city
- large typography
- side-by-side architecture and metadata where useful

Tablet:
- preserve the city visualization
- simplify peripheral metadata

Mobile:
- headline first
- city second
- touch timeline third
- stats fourth
- building inspection as bottom sheet
- matching as SPACE → MATCH → NEED
- constraint controls stacked vertically

No horizontal page scrolling.
No clipped typography.
No tiny controls.
Touch targets should be comfortably tappable.

Test at narrow mobile widths and common tablet/desktop widths.
