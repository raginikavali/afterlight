# VISUAL QA

Act as a hostile-but-fair design reviewer.

Inspect the running page, not just source code.

Check:
- first 5-second comprehension
- hero composition
- city readability
- timeline affordance
- building hover/click
- match behavior
- rejected match behavior
- scenario switching
- operator controls
- pilot CTA
- mobile layout
- reduced motion
- typography
- spacing
- overflow
- contrast
- console errors

Ask:
“Could this be mistaken for a generic AI/SaaS template?”

If yes, redesign the offending section.

Ask:
“Does this animation explain something?”

If no, remove it.

Ask:
“Can a skeptical evaluator understand why this is worth a pilot?”

If unclear, improve hierarchy/copy rather than adding more features.

Never invent evidence.
