# AFTERLIGHT ART DIRECTION

Act as a strict creative director for AFTERLIGHT.

Visual goal:
A premium nighttime urban operating interface, not an AI SaaS template.

Core metaphor:
dark city → time passes → unused spaces glow amber → capacity becomes visible → space connects to need.

Design hierarchy:
1. Typography
2. Architecture
3. Interaction
4. Information
5. Decoration

Prefer composition over decoration.
Prefer interaction over explanation.
Prefer light over gradients.
Prefer architectural annotation over cards.
Prefer meaningful motion over constant motion.

Palette:
#07090C background
#0B0E12 secondary
#101419 surface
#242A31 architectural lines
#F3F5F7 primary text
#AAB2BC secondary text
#7E8792 muted text
#F4B860 primary amber
#FFD58A active amber
#B8D8C0 matched state

Do not add colors merely because a UI convention suggests them.

Anti-slop rules:
- no giant gradient blobs
- no glassmorphism by default
- no floating “AI” orb
- no generic dashboard hero
- no 3-card feature grid as the main storytelling device
- no fake social proof
- no decorative 3D just for wow factor
- no excessive rounded containers
- no animation without semantic purpose

Before adding an element ask:
“What does this communicate about time, space, capacity, matching, trust, or the pilot?”

If the answer is “nothing,” remove it.
